MineMakers 0.2.1 setup correction

EXTRACT THE WHOLE ZIP before launching anything.

The extracted ZIP contains:
  Start-MineMakers-Overlay.cmd    <-- double-click this to launch the UI helper
  tools/desktop_overlay.py       <-- the helper code
  tools/desktop_protocol.py      <-- required alongside the helper
  Minecraft/mods/                <-- the prebuilt Fabric JAR
  Trailmakers/                   <-- Lua files to copy into the actual game mod

The GAME MOD folder contains:
  main.lua
  data_static/
  data_dynamic_willnotbeuploadedtoworkshop/
    trailmakers.frame
    minecraft.frame
    view.frame

The .py files do NOT belong in the frame folder. Trailmakers does not create them.
They are in the tools folder of this extracted ZIP.

1. Install Python 3.10+ if necessary. The helper needs no pip packages.
2. Keep the Trailmakers mod running. Double-click Start-MineMakers-Overlay.cmd.
3. Paste the full Explorer path to the EXISTING folder containing trailmakers.frame:
   .../data_dynamic_willnotbeuploadedtoworkshop
4. Use that exact same full path in Minecraft's /minemakers link "..." command.
5. Keep Minecraft running behind borderless/windowed Trailmakers. Focus Trailmakers
   and press F8. F8 again releases the helper.

The helper creates desktop.frame. Minecraft creates overlay.bgra after capture is
active. If neither appears, the overlay has not started; the old three frame files
alone do not mean that the HUD overlay is running.

If 0.2 is already installed, this release does not change Minecraft gameplay.
You can use the new launcher/tools with the existing 0.2 JAR and Lua files.
If installing the included 0.2.1 JAR, remove the older MineMakers JAR first.
See docs/UPGRADE-0.2.md for the full setup and current limitations.
